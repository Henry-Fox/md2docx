Markdown 转 Word DOCX 在线工具

DocDraft 可以在浏览器中将 Markdown 文档转换为 Word DOCX 文件，适合公文、论文、技术文档、周报和通用办公文档排版。

核心能力

  • 支持 Markdown 实时预览，并导出为 DOCX。
  • 支持模板管理，可配置页面、正文、标题、字号、字体和行距。
  • 支持从 Word 文档导入格式，快速生成可复用模板。
  • 纯前端运行，构建后可以作为静态 HTML 独立部署。

常见问题

Markdown 怎么转成 Word？

将 Markdown 内容粘贴到编辑器，选择合适模板，然后点击导出 DOCX。

是否支持公文或论文格式？

支持。你可以使用内置模板，也可以从已有 Word 文档导入格式生成自己的模板。

是否可以离线使用？

可以。运行 npm run build 后，dist 目录中的文件可作为静态网站部署或本地使用。
